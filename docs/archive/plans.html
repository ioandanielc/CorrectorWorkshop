The problem

Poisson disk constraint correction

Given a 2D point cloud where noise has pushed some pairs closer than the minimum distance rd, the model predicts a displacement vector for each point to restore validity.

The challenge scales non-linearly: fixing one violating pair can push a point into a new violation. In packed clouds (near maximum density ~462 pts at rd=0.05), every correction is constrained by legal neighbours on all sides.

Key insight: the model must be surgical — applying near-zero displacement to legal points and precisely targeting only violating pairs. A global push creates new violations in packed geometry.

Step 11 · Next — scaling to N=2500

Two inference approaches — run both, compare on real data

11a · Sparse radius graph + MIC

No retraining. Cutoff 2×rd per point → 10–20 edges instead of 2499. Memory: 3.2 GB → ~13 MB per cloud.

MIC: rel_pos -= round(rel_pos) — cross-boundary violations look identical to interior ones. Exact, lossless. Post-correction modulo wraps back to [0,1]².

one new file · scatter_add
11b · 5×5 domain tiling

Domain decomposition. Partition [0,1]² into 25 cells → ~100 pts each → apply a model trained at N≈100 (packedness ≈ 0.22). 25 cells run in parallel.

Cross-boundary fix: extend each cell outward by rd (overlap halo). Include ~10–20 neighbour points from adjacent cells; update only core points. Every violation seen by at least one cell.

Normalization: center-only per cell — no scale change — so rd stays at trained value. Re-scaling to [0,1]² would inflate rd to 0.25, physically impossible at N≈100.

Step 12 — The decisive test

Synthetic experiments establish the trade-off: model6 wins on raw single-pass clearance, model9 wins on surgical precision and displacement conservation. On real packed data with no slack, model6's global push is expected to cascade new violations; model9's violation-weighted approach is the hypothesis to confirm. This is not a generalisation sanity check — it is the benchmark that actually matters.

Primary metric

viol/cloud before vs after. Must decrease; must not increase anywhere. Run all model checkpoints on the same dataset.

Cascade check

Count new violations introduced vs resolved after correction. Net = resolved − introduced. Model6 expected high introduction rate in packed clouds.

NN drift

Mean nearest-neighbour / rd after correction. Must stay close to 1.0 — ballooning means the corrector is shoving legal structure aside.

Zero-violation stability

Feed clean real clouds (no violations). Model must output near-zero displacement. Any significant movement on a legal packed cloud breaks global structure.

Implementation: normalise real clouds to [0,1]², infer rd from 5th-percentile NN distance on clean examples, run all checkpoints, produce comparison table and visualisations in analysis/eval_real.py.

Model 6 — Violation-Aware Edge Network

What it does

Given a noisy 2-D point cloud that violates the Poisson disk constraint (all point pairs must be at least rd = 0.05 apart), the model predicts a per-point displacement vector that moves each point just enough to restore legality — while keeping displacements as small as possible.

The input is a batch of N-point clouds (B, N, 2). The output is a matching set of displacement vectors (B, N, 2) which are added back to the noisy input to produce the corrected cloud.

Why an edge network?

The Poisson disk constraint is fundamentally pairwise — only the distance between point i and point j determines whether a violation exists. Earlier models (1–5) used global self-attention over raw coordinates, which had to learn to compute distances from scratch.

Model 6 instead builds explicit edge features for every ordered pair (i→j) — including a direct violation signal relu(rd − dist) that is non-zero only where the constraint is broken. This gives the network exact physical feedback with no learned approximation.

Forward Pass

Stage by Stage

① Input

Noisy Point Cloud

A batch of B clouds, each with N=50 points in 2-D. The cloud has been centered (centroid subtracted) by the DataProcessor before entering the model. Points violate the Poisson disk constraint — some pairs are closer than rd = 0.05.

② Edge Features

Pairwise Geometry

For every ordered pair (i→j) we compute three quantities: relative position xi − xj (2 values), distance ‖xi − xj‖ (1 value), and violation depth relu(rd − dist) (1 value). This last term is zero for legal pairs and positive only where the constraint is broken — it is the exact physical signal the model needs.

③ Edge MLP

Embedding Each Pair

A small MLP (weights shared across all N² pairs) maps the 4-D edge feature into a 128-D embedding. This learns what it means for a pair to be "barely violating", "severely violating", or "safely spaced". LayerNorm is applied per-layer to stabilise training across the large range of violation depths.

④ Aggregate

Collect Neighbour Context

Self-edges (i = j) are zeroed first — they have dist=0 and violation=rd, which is spurious. Then all neighbour embeddings are summed over j, giving each point a 128-D context vector that encodes its full local violation landscape. Current limitation: sum weights all neighbours equally — addressed in model 7.

⑤ Output MLP

Predict Displacement

A second MLP maps each point's 128-D context vector to a 2-D displacement. The displacement is added to the original (noisy) point position via the skip connection. There is no output clamping — the model is free to predict any magnitude, relying on the λ₂ displacement regularisation term in the loss to keep corrections small.

Using relative position (not absolute) makes the representation translationally invariant — the model sees the same features regardless of where the cloud sits in space. Including distance as a scalar (in addition to the vector) gives rotational invariance. Self-edges are zeroed before aggregation to avoid the spurious signal a point would send to itself (dist=0 → violation=rd).

What Comes Next

Step 1  ▶ Running
Variable Noise

Train with noise σ sampled uniformly from [0.0, 0.03] per cloud instead of fixed σ=0.01. Forces the model to learn conditional correction magnitude — small push for small violations, larger push for severe ones — and explicitly teaches the zero-violation "do nothing" case. No architecture change; dataset config only.

dataset_config_3.yaml noise_scale_min: 0.0 noise_scale_max: 0.03
Step 2  · Model 7
Violation-Weighted Aggregation

Replace the uniform Σⱼ edge_emb[i,j] with a violation-weighted sum: each neighbour's message is scaled by its violation depth before aggregation. Non-violating neighbours (depth=0) contribute nothing; severely violating ones dominate. This means the model's output for point i is driven exclusively by the pairs that actually need fixing.

models/fixed_rd/model7.py weights = viol / (viol.sum() + ε) agg = (edge_emb × weights).sum(j)
Step 3  · Trainer
Iterative Unrolling

Unroll K=2–3 forward passes per training step: apply the predicted displacement, recompute edge features on the corrected cloud, run the model again, accumulate loss across all steps. This teaches the model to produce corrections that compose well — each pass resolves the worst remaining violations, leaving fewer for the next. Critical prerequisite before tackling packed scenarios (step 5) where single-pass correction hits a combinatorial ceiling.

training/trainer.py unroll_steps: 3 loss = Σₖ loss(corrected_k)
Step 4  · Data
Larger Point Clouds

Scale from N=50 to N=100 then N=200, keeping rd=0.05 and the same unit box. Tests whether the O(N²) edge network stays tractable at larger N and whether the per-pair features learned at N=50 transfer to richer clouds. At N=100 compute is ~4× per iteration; at N=200 it is ~16×, so training duration will need to be adjusted accordingly.

dataset_config_4.yaml (N=100) dataset_config_5.yaml (N=200)
Step 5  · Data
Packed Scenarios

Push packing density to 50–70% of the triangular lattice maximum (~N=200–300 at rd=0.05, versus ~11% density today). At high density, a single displaced point may violate 4–6 neighbours simultaneously; fixing it pushes it into others, creating conflict chains. This is the hardest non-periodic regime and the main motivation for iterative unrolling (step 3). No new architecture needed — same model, different data.

N ≈ 200–300 at rd=0.05 ~50–70% of max packing requires step 3 first
Step 6  · Model 8
Periodic Boundary Conditions

Move to a toroidal domain (the box wraps — left edge meets right, top meets bottom). Boundary effects disappear: every point is equivalent, and the max packing density is the same everywhere. Two changes to the model: (1) replace rel_pos = xi − xj with the minimum image convention rel_pos = rel_pos − round(rel_pos) so pairs across the boundary are computed correctly; (2) wrap corrected coordinates back into the box with x_corrected = (x + Δx) % 1.0. The DataProcessor centering step is dropped — meaningless on a torus, and model 7/8 are already translationally invariant by construction. Requires a custom PBC-aware Poisson disk generator (scipy only supports walled boxes).

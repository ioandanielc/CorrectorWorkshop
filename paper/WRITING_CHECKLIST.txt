--------------------------------------------------------------------------------
S1  INTRODUCTION  (~0.6 page)
--------------------------------------------------------------------------------
[ ] SPH accuracy rests on spatially balanced neighbourhoods; the equations never
    enforce this explicitly.
[ ] The discrete kernel-gradient sum KG_i = sum_j grad-W_ij V_j is identically
    zero on a symmetric arrangement; disordered states give large residuals.
[ ] States violating minimum spacing cannot start/restart a simulation.
[ ] Classical remedies (shifting, transport-velocity, packing) repair INSIDE the
    solver loop, iteratively, every step.
[ ] Question: can the repair be learned ONCE as a standalone operator?
[ ] The hook: constraint-only predecessor (model9) satisfied spacing but
    QUADRUPLED the residual (1.278 vs 0.326 uncorrected) -> restarts unusable.
    "Fixing the geometry is not the same as fixing the physics."
[ ] Thesis: physics must enter TWICE — as loss residual AND as fixed kernel in
    the architecture.
[ ] Contribution 1: deployable corrector. Trained on 49-particle lattices,
    corrects real 2,500-particle trajectory to |KG| 0.127 (2.2x better than
    Transport Velocity), 0.19 s/state CPU, validated by actual re-simulation,
    transfers to bounded obstacle scene at 11.7x coordinate scale.
[ ] Contribution 2: physics term is an OPTIMISATION ENABLER, not a regulariser.
    Ablating it -> training diverges + reproduces predecessor failure (1.471).
    Neither loss part works alone.
[ ] Contribution 3: small-N benchmarks MISRANK architectures vs deployment
    (twice); single-mechanism ablations isolate what transfers (fixed kernel
    + additive aggregation).
[ ] Contribution 4: deployment guidance with measured uncertainty (k-sweep,
    invisible degenerate mode, claim audit vs seed variance).

S3  METHOD  (~0.9 page, one equation block)
--------------------------------------------------------------------------------
[ ] L-round message passing on the radius graph; node states start at ZERO
    (all signal enters through geometry).
[ ] Equation elements: e_ij = MLP_e[h_i, h_j, x_i-x_j, d_ij, relu(rd-d_ij)];
    h_i <- h_i + MLP_n( sum_j w_ij e_ij );
    w_ij = (1-(d_ij/rc)^2)^2, normalised per particle;
    output dx_i = tanh(MLP_o(h_i)) * 1.2 rd; minimum image throughout.
[ ] Design choice 1 — the weight is a FIXED SPH-kernel-shaped function, not
    learned attention: smooth, compact support (=0 at d>=rc), scale-free after
    rd-normalisation; EVERY near pair contributes (violating or not) -> makes
    the KG signal visible; overlap depth stays explicit via relu(rd-d).
    Forward-reference S4.5: this + additive aggregation is what transfers.
[ ] Design choice 2 — receptive field matched to physics: rc = 2*dx (= SPH h),
    L=4 -> reach ~8 spacings >= quintic kernel support 6*dx -> KG symmetry is
    learnable as a LOCAL property -> size generalisation.
[ ] Translation-invariant by construction; deliberately NOT rotation-
    equivariant (fixed simulation frame).
[ ] Deployment: dense NxN at training; identical weights over explicit edge
    list at deployment (EXACT, kernel vanishes beyond rc; sparse=dense to
    4e-7). Per pass: scale by rd_train/rd_test -> periodic edge list -> one
    forward -> unscale; k passes total.
[ ] Solid boundaries: ghost particles fill obstacle interior at spacing rd,
    concatenated each pass, RE-PINNED after (solid never drifts).

S4.1  SETUP
--------------------------------------------------------------------------------
[ ] Task statement + KG equation (W quintic, h = 2*dx; mean |KG_i| primary
    metric, lower better).
[ ] Data: online generation, unit torus, 7x7 lattice N=49, spacing 1/7,
    rd = 0.14 ~ 0.98*spacing, bounded jitter, Gaussian noise amplitude in
    [0, sigma*rd], sigma = 0.6 standard / 1.0 hard, minimum-image periodic.
[ ] Loss: L = l1 mean relu(rd - d_ij) + l2 mean|dx| + l3 mean|KG_i|^2;
    l1 = 1/rd = 7.14; l2 = 0.1*l1/(N-1) = 0.0149; l3 = 0.27.
    KG term is SOFT and TRAINING-ONLY (never enforced at inference).
[ ] Protocol (identical for every architecture): AdamW lr 1e-3 wd 1e-4, cosine,
    10k iterations, batch 32, K=5 unrolled passes with per-step detachment,
    same tanh output head, params matched to 350k +-0.8%, NO per-architecture
    tuning, degeneration claims need >=3 seeds.
[ ] Evaluation: one scorer for every arm; 64 fixed held-out clouds (synthetic);
    real N=2500 trajectory, 1002 steps, disordered regime t>=300; sim
    validation exists for the production configuration.
[ ] Uncertainty sentence (keep verbatim): spread over three identical runs is
    sigma ~9% on synthetic |KG| but 3.5% on trajectory |KG| (averages over
    2500 particles x 15 steps); differences below threshold not claimed.
[ ] Cost: 0.189 s/timestep CPU, 0.049 s GPU (N=2500, k=5).

S4.3  LOSS ABLATION (Table 3)
--------------------------------------------------------------------------------
[ ] Framing: removing KG term does not degrade — it REPRODUCES the prior
    failure. l3=0 deployed: 1.471 = 4.4x WORSE than doing nothing; adjacent to
    model9 1.278. "The ablation puts the breakage back."
[ ] Table 3 cells: full 82.9% / 0.0216 / knn 0.661 / traj 0.127 (3 seeds);
    l3=0: 17.6% / 0.1407 / 0.701 / 1.471 (4/4 degenerate);
    symmetry-only (l1=l2=0): -19.5% / 0.3948 / knn 0.132 (!) / 3.009;
    l2=0: degenerate (n=1).
[ ] Neither objective functions alone (symmetry-only shreds the arrangement:
    13% of neighbours survive).
[ ] Signal 1: removing the SYMMETRY term costs 65 points of VIOLATION
    reduction.
[ ] Signal 2: val loss minimum at iteration 500/10,000, never improves; full
    objective improves monotonically.
[ ] Signal 3: final iterate degenerates to saturated uniform translation
    (cut first if space; S4.7 carries it).
[ ] Mechanism: violation term = mean over N^2 pairs, only O(N) violate ->
    gradient dilutes as easy violations clear; KG term supplies dense
    per-particle gradient throughout.

S4.5  MECHANISM (Table 5)
--------------------------------------------------------------------------------
[ ] Setup: ablation variant bit-identical to production at baseline; one
    component swapped at a time.
[ ] The two single-mechanism rungs: nokernel (fixed kernel -> learned scalar
    gate, nothing else) and wmax (weighted mean -> weighted max, kernel kept,
    nothing else).
[ ] Table 5 grouping (trajectory |KG|):
      GOOD (kernel AND additive): nonorm 0.1177-0.1204; model12 0.1230-0.1273
      REST: GNS 0.1319-0.1427; maxagg 0.1434-0.1495; nokernel 0.1486-0.1703;
            wmax 0.1538
    NO OVERLAP: 0.118-0.127 vs 0.132-0.170, eleven runs, four architectures,
    three aggregation schemes.
[ ] Changing EITHER component alone moves the model out of the good group.
[ ] The argument: |KG| is a weighted SUM of kernel gradients -> reproducing it
    at unseen cardinality needs the distance weighting (scale-free) AND the
    summation. Learned weighting fits training-scale statistics; max discards
    balance information.
[ ] Per-particle normalisation NOT required: nonorm transfers marginally
    better than production.

S4.7  INVISIBLE FAILURE MODE (Fig 3 -> appendix)
--------------------------------------------------------------------------------
[ ] ~Half of runs for several variants degenerate to a SATURATED UNIFORM
    TRANSLATION (every particle same vector, at the output bound).
[ ] Invisible to |KG| and illegal% (all loss terms depend on relative
    positions only) — cloud translates a full domain length over 5 passes
    while metrics read "unchanged".
[ ] tanh-saturation trap: saturated head -> vanished gradient -> no recovery.
[ ] Initialisation-dependent (DGCNN sigma=1.0: 2 of 4 seeds).
[ ] Countermeasures: (i) log bulk-drift |mean dx| / mean|dx| every eval;
    (ii) degeneration claims only at 3/3 seeds — only l3=0 meets it (4/4).
[ ] Fig 3: displacement decomposed; working models 3-9% bulk; PointNet local
    component ~1e-4 = pure translation.
[ ] KEEP IN MAIN BODY even if section moves: the two bolded sentences
    (invisibility + initialisation-dependence).

S5  CONCLUSION + OUTLOOK
--------------------------------------------------------------------------------
[ ] Physics enters twice (loss residual + kernel in weighting) — both
    load-bearing, each shown by ablation.
[ ] Recommendation to the field: deployment-scale evaluation is mandatory for
    learned particle operators (benchmark inverted rankings twice).
[ ] Outlook 1: validate k=8 / N=100 by re-simulation.
[ ] Outlook 2: 3-D (only the KG primitive needs 3-D normalisation).
[ ] Outlook 3: disorder level as physical temperature — uncharted.
[ ] Outlook 4: other particle methods (MD ICs with energy-based residual).
